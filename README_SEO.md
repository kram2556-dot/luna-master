# SEO checklist

The site includes a bilingual description, canonical URL, robots directives, Open Graph tags, Twitter Card metadata, JSON-LD Person schema, `robots.txt`, and `sitemap.xml`.

Before production launch, replace the demo Pages URL in `index.html`, `robots.txt`, and `sitemap.xml` if a custom domain is added. Also replace the demo image, email, social links, WhatsApp number, and Formspree ID. Submit `/sitemap.xml` in Google Search Console after the final domain is live.
