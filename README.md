# Luna Beauty Studio — Makeup Artist Portfolio

A polished Arabic-first, bilingual static portfolio for a makeup artist. Built from the original Youssef El-Sayed portfolio visual system and redesigned for beauty/editorial work.

## Included

- Hero section with the supplied Unsplash image
- 12-image makeup gallery with category filters and lazy loading
- Before/after comparison slider
- Services for bridal, soft glam, and editorial makeup
- Instagram-style feed with the supplied image set
- Client testimonials with portrait images
- Arabic / English toggle
- WhatsApp booking CTA and contact form placeholder
- Responsive layout, reveal animations, and mobile navigation

## Run locally

Open `index.html` directly or serve the folder with any static server. All visual assets are remote Unsplash URLs supplied for the demo.

> Replace the placeholder WhatsApp number, email, Instagram URL, and form handling before production launch.
